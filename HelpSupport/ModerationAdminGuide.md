# Moderation Admin Guide — Жалобы, апелляции, блокировки

**Назначение:** Инструкция для команды модерации по работе с жалобами пользователей, удалёнными материалами, апелляциями и заблокированными аккаунтами.  
**Аудитория:** Модераторы, администраторы платформы.  
**Правовая основа:** DSA Art.14–18 · GDPR Art.32 · Google Play Child Safety Standards

---

## 1. Принципы (обязательны по DSA)

| Принцип | Требование |
|---|---|
| Анонимность репортёра | Нарушитель **никогда** не видит, кто на него пожаловался |
| Statement of Reasons | При каждом удалении нарушитель получает письменное объяснение с указанием конкретного правила |
| Право на апелляцию | Каждое решение об удалении контента подлежит оспариванию (Appeal) |
| Человеческая проверка | Апелляции рассматриваются живым модератором (не автоматикой) |
| Сроки | Жалоба обрабатывается ≤ 24 ч (CSAE/незаконный контент) или ≤ 5 рабочих дней (остальное) |

## 3. Moderation Dashboard — что видит модератор

### 3.1 Карточка тикета

| Поле | Видимость |
|---|---|
| Тикет #ID | ✅ модератор |
| Репортёр: @username (ID) | ✅ модератор · ❌ нарушитель · ❌ другие пользователи |
| Нарушитель: @username (ID) | ✅ модератор |
| Контент (превью поста / комментария / профиля) | ✅ модератор |
| Категория жалобы | ✅ модератор |
| Детали репортёра (текст) | ✅ модератор |
| История нарушений нарушителя | ✅ модератор |
| Trust Score репортёра | ✅ модератор |
| Дата / время | ✅ модератор |

### 3.2 Действия модератора

| Действие | Результат |
|---|---|
| **Remove content** | Контент скрыт для всех · нарушителю Statement of Reasons · кнопка Appeal |
| **Dismiss** | Тикет закрыт без действий · репортёру «No violation found» |
| **Warn user** | Нарушителю предупреждение (страйк +1) |
| **Suspend account (temp)** | Аккаунт заморожен на N дней · нарушителю Email + In-app |
| **Permanently ban** | Аккаунт удалён · применяется после 3 страйков (или 1 за CSAE) |
| **Escalate to CSAE team** | Тикет уходит в отдельную очередь · контент блокируется немедленно |
| **Report to NCMEC** | Автоматическая форма CyberTipline (только CSAE) |

## 4. Система страйков

| Страйк | Действие |
|---|---|
| 1-й страйк | Предупреждение + удаление контента |
| 2-й страйк | Временная блокировка (7 дней) |
| 3-й страйк | Постоянная блокировка аккаунта |
| CSAE (любой) | Немедленная постоянная блокировка + репорт в NCMEC |

> Страйки хранятся **постоянно** (не сбрасываются автоматически).  
> Снять страйк может только модератор через Dashboard после успешной апелляции.

---

## 5. Защита от злоупотребления жалобами (Trust Score)

Некоторые пользователи используют Report как инструмент травли (массово жалуются на конкурентов/личных врагов).

| Сигнал | Действие |
|---|---|
| > 10 жалоб за 24 ч от одного пользователя | Автофлаг «possible abuse» в Dashboard |
| > 80% жалоб от пользователя закрыты как «No violation» | Снижение Trust Score |
| Trust Score < порога | Жалобы этого пользователя не запускают автоматические скрытия |
| Trust Score = 0 | Жалобы поступают в очередь, но не обрабатываются приоритетно |
| Подтверждённое злоупотребление | Предупреждение / временный бан репортёра |

> Trust Score репортёра не раскрывается пользователям.

## 6. Обработка апелляций

### Требования DSA Art.17

- Апелляцию рассматривает **человек** (не автоматика).
- Ответ в течение **5 рабочих дней**.
- Ответ должен содержать **обоснование** (почему удаление подтверждено или снято).

### Процесс

```
Апелляция получена
      │
      ▼
Модератор 2 (не тот, кто принял первоначальное решение)
рассматривает:
  - Оригинальный контент
  - Причину удаления
  - Текст апелляции пользователя
      │
  ┌───┴───────────────┐
  ▼                   ▼
Апелляция           Апелляция
удовлетворена       отклонена
  │                   │
  ▼                   ▼
Контент             Удаление
восстановлен        подтверждено
Страйк снят         Страйк остаётся
Email + In-app      Email + In-app
```

## 7. Блокировки — Blocked Users

### 7.1 Откуда берётся блокировка

| Источник | Механизм |
|---|---|
| Пользователь сам заблокировал | Профиль → ⋯ → Block |
| Рекомендация после подачи жалобы | Экран A-4 (confirmation) → «Block @user» |
| Модератор заблокировал аккаунт | Admin Dashboard → Suspend / Ban |

### 7.2 Где пользователь видит заблокированных им пользователей

**Путь в приложении:**  
`Settings → Privacy & Visibility → Safety & Blocked Accounts → Blocked list`

```
Blocked Accounts

[Список заблокированных]

┌─────────────────────────────────────┐
│  👤 @anna_k                          │
│  Blocked on: 12 Apr 2026            │
│  [Unblock]                           │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│  👤 @spammer_99                      │
│  Blocked on: 5 Mar 2026             │
│  [Unblock]                           │
└─────────────────────────────────────┘

[Кнопка: «Add» — заблокировать по имени пользователя]
```

### 7.3 Что видит заблокированный пользователь

| Ситуация | Что показывается заблокированному |
|---|---|
| Пытается открыть профиль блокировщика | «Profile not found» или «This account is private» |
| Пытается написать сообщение | Поле ввода недоступно |
| Ищет блокировщика в поиске | Не отображается в результатах |
| Получает уведомление о блокировке | ❌ Не получает — это защищает блокировщика |

### 7.4 Разблокировка

- Только сам пользователь может разблокировать.
- Разблокировка доступна через `Settings → Privacy & Visibility → Safety & Blocked Accounts`.
- Модератор не может разблокировать — это личный выбор пользователя.

## 8. CSAE — Экстренный протокол

> 🔴 CSAE = Child Sexual Abuse / Exploitation. Стандартный процесс модерации не применяется.

| Шаг | Действие | Срок |
|---|---|---|
| 1 | Жалоба поступила с категорией «Child Safety» | Автоматически |
| 2 | Контент **немедленно скрыт** (до проверки модератором) | Автоматически |
| 3 | Тикет помечен 🔴 CSAE — приоритет #1 | Автоматически |
| 4 | Модератор проверяет контент | ≤ 1 ч |
| 5 | Если CSAE подтверждено: аккаунт **немедленно заблокирован навсегда** | ≤ 1 ч |
| 6 | Обязательный репорт в **NCMEC CyberTipline** | ≤ 24 ч (закон США) |
| 7 | Сохранение всех данных (контент, IP, ID) для правоохранителей | Бессрочно |

> ⚠️ **Репортёр по CSAE НЕ остаётся анонимным для правоохранительных органов.** При официальном запросе полиции / Интерпола / NCMEC — предоставляются данные обеих сторон.

## 9. Хранение данных о жалобах (GDPR)

| Тип данных | Срок хранения | Основание |
|---|---|---|
| Тикет жалобы (метаданные) | 3 года с даты закрытия | GDPR Art.5(1)(e) · DSA (возможные аудиты) |
| Удалённый контент (копия) | 6 месяцев (для апелляции) | DSA Art.17 |
| CSAE контент | Хранить до закрытия дела или запроса NCMEC | CVAA · PROTECT Our Children Act |
| Данные репортёра (ID) | 3 года | DSA Art.24 (прозрачность) |
| Страйки пользователя | Бессрочно | Защита платформы |
| Trust Score | Бессрочно (пересчёт в реальном времени) | Защита платформы |
