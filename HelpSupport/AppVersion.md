# App Version

**Раздел:** Settings → Help & Support → App Version  
**Обязательно:** 💡 (рекомендация App Store — полезно для поддержки)

---

## Назначение

Показывает текущую версию приложения. Нужен для:
- Пользователь может сообщить версию в поддержку при обращении.
- Поддержка может попросить обновиться, если версия устарела.

---

## Структура элемента

> Это не отдельный полноэкранный раздел. Это статичная строка в списке Help & Support.

```
Settings → Help & Support

...
Open Source Licenses         →
──────────────────────────────
App Version                  1.0.4 (build 204)
```

---

## Что показывать

| Элемент | Пример | Обязательно |
|---|---|---|
| Версия | `1.0.4` | 💡 |
| Build number | `(build 204)` | 💡 |
| Действие по тапу | «Copied to clipboard» | 💡 (удобно для поддержки) |

---

## Реализация

- Значение берётся из `CFBundleShortVersionString` (iOS) / `versionName` (Android) — не хардкодится.
- При тапе на строку — копировать версию + build в буфер обмена (удобно для тикетов поддержки).
