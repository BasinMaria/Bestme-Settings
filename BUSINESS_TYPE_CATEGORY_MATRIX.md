# Business Type × Category Adaptive Matrix
# Адаптивная матрица: Тип бизнеса × Категория

## Executive Summary / Краткое резюме

This document defines how Business Profile Identity Blocks adapt based on **TWO factors**:
1. **Business Type** (7 types: Specialist, Place, Education, Services, Products, Activities, B2B)
2. **Bestme Category** (6 wellness categories)

Этот документ определяет, как блоки бизнес-профиля адаптируются по **ДВУМ факторам**:
1. **Тип бизнеса** (7 типов)
2. **Категория Bestme** (6 категорий здорового образа жизни)

**Key Insight / Ключевая идея:**
The same Business Type shows different Identity Blocks depending on the wellness category.

Example: "Place" in Healthy Eating = Restaurant (menu) vs "Place" in Physical Activity = Gym (equipment, classes).

---

## The 6 Bestme Categories / 6 категорий Bestme

1. 🍎 **Healthy Eating / Здоровое питание**
   - Nutrition, food, diet, eating habits
   - Питание, еда, диета, пищевые привычки

2. 💪 **Physical Activity / Физическая нагрузка**
   - Exercise, sports, fitness, movement
   - Упражнения, спорт, фитнес, движение

3. 🧘 **Mental Balance / Душевное равновесие**
   - Mindfulness, therapy, meditation, emotional health
   - Осознанность, терапия, медитация, эмоциональное здоровье

4. ✨ **Aesthetics & Hygiene / Эстетика и гигиена**
   - Beauty, skincare, personal care, appearance
   - Красота, уход за кожей, личная гигиена, внешний вид

5. 🌍 **Environment / Окружающая среда**
   - Ecology, sustainability, green living, nature
   - Экология, устойчивость, зеленый образ жизни, природа

6. ⏰ **Daily Routine / Режим дня**
   - Sleep, productivity, time management, habits
   - Сон, продуктивность, управление временем, привычки

### Matrix Structure / Структура матрицы


## Implementation Guidelines
## Руководство по внедрению

### Database Schema / Схема базы данных

```javascript
BusinessProfile {
  id: UUID,
  
  // Required fields / Обязательные поля
  name: String,
  businessType: Enum, // Specialist, Place, Education, Services, Products, Activities, B2B
  category: Enum, // HealthyEating, PhysicalActivity, MentalBalance, Aesthetics, Environment, DailyRoutine
  description: String,
  format: Enum, // Online, Offline, Hybrid
  contact: {
    phone: String,
    email: String
  },
  
  // Universal blocks / Универсальные блоки
  reviews: [...],
  posts: [...],
  mediaGallery: [...],
  location: {...},
  openingHours: {...},
  
  // Identity blocks (adaptive) / Блоки идентичности (адаптивные)
  identityBlocks: {
    // Dynamically populated based on businessType × category
    // Динамически заполняется на основе businessType × category
    
    // Example for Place × HealthyEating:
    menu: {
      sections: [...],
      dietaryOptions: [...],
      cuisineType: String
    },
    
    // Example for Place × PhysicalActivity:
    equipmentList: [...],
    classesSchedule: [...],
    membershipPlans: [...]
  }
}
```

### UI Logic / Логика UI

```javascript
function getIdentityBlocks(businessType, category) {
  const MATRIX = {
    'Place': {
      'HealthyEating': ['menu', 'dietaryOptions', 'cuisineType', 'chefInfo'],
      'PhysicalActivity': ['equipmentList', 'classesSchedule', 'membershipPlans', 'trainers'],
      'MentalBalance': ['programs', 'teachers', 'atmosphere'],
      // ...
    },
    'Specialist': {
      'HealthyEating': ['specializations', 'certifications', 'servicesMenu', 'approach'],
      'PhysicalActivity': ['specializations', 'certifications', 'trainingStyle', 'servicesMenu'],
      // ...
    },
    // ... other types
  };
  
  return MATRIX[businessType][category] || [];
}

function renderProfileForm(businessType, category) {
  // 1. Render universal fields
  renderUniversalFields();
  
  // 2. Get relevant identity blocks
  const identityBlocks = getIdentityBlocks(businessType, category);
  
  // 3. Render only relevant identity blocks
  identityBlocks.forEach(block => {
    renderIdentityBlock(block);
  });
}
```

### Validation Rules / Правила валидации

**Universal Validation:**
- Business Name: required, 3-100 chars
- Business Type: required, one selection
- Category: required, one selection
- Description: required, 100-500 chars
- Format: required (Online/Offline/Hybrid)
- Contact: at least one (phone OR email)

**Identity Blocks Validation:**
- Menu (if Place × HealthyEating): at least 3 items
- Equipment List (if Place × PhysicalActivity): at least 5 items
- Services Menu: at least 1 service
- Product Catalog: at least 1 product
- Etc.
