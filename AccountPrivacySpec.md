# Bestme — Юридический анализ блока Account Privacy
## Каждое поле: законность, default, UI-пояснение, возрастные ограничения

---

## ОТВЕТ НА ВОПРОС: «По закону можно делать такое?»

**Короткий ответ:** Да, можно — с точными оговорками по каждому полю.

---

## ПОЛЕ 1: Private account (Закрытый аккаунт)

| Параметр | Значение |
|---|---|
| **variable_name** | `account_private` |
| **Тип** | Toggle: On / Off |
| **Default для 18+** | `OFF` (открытый профиль) |
| **Default для 13–17** | `ON` (закрытый профиль) |
| **⚖️ Закон** | GDPR Art.25 · DSA Art.28 |

### ✅ Default OFF для пользователей 18+ — ЗАКОННО

**GDPR Art.25 («Privacy by Default»)** НЕ обязывает делать все профили закрытыми по умолчанию.
Он требует **минимизации обработки данных**, соответствующей назначению сервиса.
Если назначение сервиса — публичная социальная сеть, открытый профиль является **законной целью**.

Прецеденты: Instagram, TikTok, Facebook, LinkedIn — всё это публичные профили для взрослых по умолчанию.
Надзорные органы (французский CNIL, британский ICO, нидерландский AP) это подтверждают.

**Условие**: при регистрации пользователь должен быть **явно уведомлён**, что его профиль будет публичным.

### ⚠️ Default OFF для пользователей 13–17 — НЕЗАКОННО

**DSA Art.28(3)(g)** прямо обязывает: для несовершеннолетних настройки конфиденциальности должны **по умолчанию** не делать профиль видимым всем.

> Цитата из DSA Art.28(3): *"Providers… shall not present advertisements based on profiling using personal data of the recipient… where they are aware with reasonable certainty that the recipient is a minor."*
>
> DSA Art.28(1)(d): *"…take measures to ensure a high level of privacy, safety and security of minors…"*

**Вывод:**
- **18+** → Default `OFF` (открытый) ✅ законно
- **13–17** → Default `ON` (закрытый) ⚖️ обязательно
- **<13** → регистрация должна быть заблокирована ⛔ COPPA · DSA Art.28(2)

### UI-пояснение для пользователя (UI copy)

**EN:**
> When your account is private, only people you approve can see your posts, photos, and friends list. Your name, profile photo, and bio are always visible to everyone.

**RU:**
> Когда аккаунт закрыт, ваши посты и список друзей видят только одобренные вами пользователи. Ваше имя, фото профиля и описание всегда видны всем.

## ПОЛЕ 2: Profile in search results (Показывать профиль во внутреннем поиске)

| Параметр | Значение |
|---|---|
| **variable_name** | `profile_searchable` |
| **Тип** | Toggle: On / Off |
| **Default** | `ON` |
| **⚖️ Закон** | GDPR Art.17 (право на забвение = opt-out) |

### ✅ Default ON — ЗАКОННО

Внутренний поиск по пользователям — **основная функция социальной сети**. Показываться в нём соответствует GDPR: это законная цель (Art.6(1)(b) — исполнение договора).

Пользователь имеет право **в любой момент отключить** (GDPR Art.17 — право на забвение применительно к поиску).
Никакой закон не требует, чтобы внутренний поиск был выключен по умолчанию.

**Важно:** Если пользователь отключает `profile_searchable = OFF`, это НЕ означает удаление аккаунта. Профиль просто перестаёт появляться в результатах поиска.

### UI-пояснение

**EN:**
> When off, your profile won't appear in search results. People who already follow you can still see your profile.

**RU:**
> Если выключено, ваш профиль не будет появляться в результатах поиска. Те, кто уже подписан, по-прежнему видят ваш профиль.

## ПОЛЕ 3: SEO-indexing (Индексация в Google/Yandex)

| Параметр | Значение |
|---|---|
| **variable_name** | `seo_indexable` |
| **Тип** | Toggle: On / Off |
| **Default** | `OFF` ← **СТРОГО ОБЯЗАТЕЛЬНО** |
| **⚖️ Закон** | GDPR Art.25 (Privacy by Default) |

### ✅ Default OFF — ОБЯЗАТЕЛЬНО ПО ЗАКОНУ, НЕЛЬЗЯ МЕНЯТЬ

**GDPR Art.25(2)** прямо требует: настройки конфиденциальности **по умолчанию** должны обеспечивать максимальную защиту.

Публикация данных в интернет (передача внешним поисковикам — Google, Yandex, Bing) — это **расширение обработки за пределы необходимой цели** социальной сети. Согласно принципу минимизации данных (Art.5(1)(c)) это недопустимо без явного opt-in.

**Что произойдёт, если поставить Default ON?**
- Это нарушение GDPR Art.25 — штраф до 10 млн € или 2% оборота (Art.83(4))
- CNIL уже штрафовала сервисы за подобное (дело Google 2019, 50 млн €)

**Если пользователь включает SEO (переводит в ON):**
- Это добровольный явный opt-in — законно ✅
- Нужен дополнительный баннер/пояснение, что данные будут доступны в поисковиках

### UI-пояснение

**EN:**
> When on, your profile may appear in Google and other search engines. Off by default to protect your privacy.

**RU:**
> Если включено, ваш профиль может появляться в Google и других поисковых системах. По умолчанию выключено для защиты вашей приватности.

## ПОЛЕ 4: Activity status (Сетевой статус «В сети»)

| Параметр | Значение |
|---|---|
| **variable_name** | `online_status_visible` |
| **Тип** | Toggle On / Off ИЛИ ENUM (рекомендуется) |
| **Default** | `FRIENDS` — **НЕ EVERYONE** |
| **⚖️ Закон** | GDPR Art.25 · ePrivacy Directive |

### ⚠️ Default ON (для всех) — РИСКОВАННО, нужна корректировка

Показывать статус «В сети» — **законно** и является UX-стандартом.
НО: Default должен быть `FRIENDS` (только друзья), а не `EVERYONE` (все).

**Почему:**
- GDPR Art.25: вывод активности **всем незнакомым пользователям** выходит за пределы необходимой цели
- Рабочая группа WP29 (сейчас EDPB): метаданные активности = персональные данные, их раскрытие неограниченному кругу лиц требует правового основания
- Facebook и Instagram используют Default = Friends/Followers

**Если у вас Toggle (On/Off), а не ENUM:**
- `ON` = видят **только друзья** ✅
- `OFF` = никто не видит

**Если у вас ENUM:**
- `EVERYONE` / `FRIENDS` / `NOBODY`
- Default = `FRIENDS`

### ✅ Default FRIENDS (или ON=только друзья) — ЗАКОННО

### UI-пояснение

**EN:**
> Your friends can see when you're active. You can turn this off at any time.

**RU:**
> Ваши друзья могут видеть, когда вы в сети. Вы можете отключить это в любой момент.

## СХЕМА РАБОТЫ ПРИВАТНОГО АККАУНТА

### Если `account_private = ON` (закрытый):
- Профиль виден: ✅ Имя · ✅ Аватар · ✅ Bio (краткое описание)
- Профиль скрыт: ❌ Посты · ❌ Список друзей · ❌ Фото/медиа · ❌ Активность

### Если `account_private = OFF` (открытый):
- Видно всё согласно индивидуальным настройкам видимости (Content Visibility, Contact Info Privacy и т.д.)

### Взаимосвязь полей:
```
account_private = ON
  └── переопределяет все настройки Content Visibility → автоматически Friends Only
  └── НЕ переопределяет email_visibility (остаётся ONLY_ME)
  └── НЕ переопределяет phone_visibility (остаётся ONLY_ME)
  └── seo_indexable автоматически = OFF (независимо от настройки пользователя)
```

## ОТВЕТЫ НА ВОПРОСЫ

### «По закону можно делать Default OFF для Private account у взрослых?»
**ДА** ✅ — для взрослых (18+) открытый профиль по умолчанию законен при условии:
1. Пользователь информирован об этом при регистрации
2. Он может изменить в любой момент
3. Несовершеннолетние 13–17 получают `ON` по умолчанию автоматически

### «Профиль в поиске ON по умолчанию — законно?»
**ДА** ✅ — для взрослых законно, право на отказ (GDPR Art.17) сохраняется

### «SEO OFF по умолчанию — это строго?»
**ДА** ⚖️ — это не просто рекомендация. GDPR Art.25 делает это обязательным.
Менять на ON — только по явному opt-in пользователя.

### «Activity status ON = нормально для соцсети?»
**ДА**, **но только если ON = видят ДРУЗЬЯ** — не весь интернет.
Если у вас Toggle (один тумблер без выбора аудитории), то ON = Friends, OFF = Nobody.
