# Open Source Licenses

**Раздел:** Settings → Help & Support → Open Source Licenses  
**Обязательно:** ⚖️ App Store (требует раскрытия сторонних библиотек)

---

## Требования

| Требование | Источник |
|---|---|
| Список использованных сторонних библиотек с их лицензиями | App Store Review |
| Указание типа лицензии (MIT, Apache 2.0, BSD и т.д.) | Условия каждой библиотеки |
| Ссылка или текст полных лицензий | Условия каждой библиотеки |

---

## Структура экрана

```
Open Source Licenses

Заголовок: «Open Source Licenses»
Подзаголовок: «BestMe uses the following open source software.»

[Список библиотек — прокручиваемый]

┌─────────────────────────────────────┐
│  React Native                        │
│  Version: x.x.x                     │
│  License: MIT                        │
│  [View License →]                    │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│  Firebase SDK                        │
│  Version: x.x.x                     │
│  License: Apache 2.0                 │
│  [View License →]                    │
└─────────────────────────────────────┘

... (все библиотеки)
```

---

## Элементы экрана

| Элемент | Обязательно |
|---|---|
| Название библиотеки | ⚖️ |
| Версия | 💡 |
| Тип лицензии | ⚖️ |
| Текст или ссылка на полный текст лицензии | ⚖️ (для GPL/LGPL — обязательно полный текст) |

---

## Рекомендация по реализации

Большинство мобильных фреймворков имеют инструменты автогенерации:

| Платформа | Инструмент |
|---|---|
| React Native / JS | `license-checker` npm пакет |
| iOS (CocoaPods) | `cocoapods-acknowledgements` |
| Android | `gradle-license-plugin` |
| Flutter | `flutter_oss_licenses` |

> 💡 Не создавайте и не обновляйте этот список вручную — используйте автогенерацию при каждом билде.
